# BIM_IA_CyP

Repositorio de un modelo BIM en formato Autodesk Revit.

## Contenido

- `REP04-CIT-XX-XX-M3-E-00001-R02/REP04-CIT-XX-XX-M3-E-00001-R02.rvt`: modelo Revit.
- `.gitignore`: excluye copias de seguridad numeradas de Revit, archivos temporales, configuraciones locales y credenciales habituales.

## Cómo abrirlo

1. Descarga o clona este repositorio.
2. Abre el archivo `.rvt` con una versión compatible de Autodesk Revit.

La versión de Revit y el contenido interno del modelo no se han verificado. No se incluyen scripts, aplicaciones ni funcionalidades de inteligencia artificial en los archivos actuales.

## Colaboración

Coordina los cambios antes de reemplazar el modelo: Git no permite fusionar automáticamente archivos binarios `.rvt`. No publiques credenciales, información personal ni modelos sin permiso para compartirlos.
